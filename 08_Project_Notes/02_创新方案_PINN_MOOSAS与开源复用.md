# 基础任务完成后的创新方案

2026-11-13。按用户最终澄清：**完成作业要求的 CFD 验证与排烟设计后，再加入 PINN、MOOSAS 或其他方法作为 innovation**。不以它们替代本次作业要求，也不将换了软件本身当成创新。本文件是研究建议，尚未实施或证明有效。

## 00 建议的研究问题

推荐主问题：**在已验证的排烟设计中，能否只用少量温度观测和物理约束，重构关键温度分布，并可靠识别不利工况？**

这是 PINN 的附加用途：让基础 CFD 结果不仅用于报告图，也成为可审查的“虚拟试验台”。创新价值取决于少测点重构是否比简单方法更有用、边界是否诚实、误差是否可量化，而不是神经网络画出了漂亮云图。

另一个可独立成章的问题：**能否复用 MOOSAS 的气流/建筑性能流程，低成本筛选补风与排烟方案，再以 CFD 验证筛选可靠性？**

PINN 和 MOOSAS 不是同一种工具，也不必绑在一起。建议选一个主创新，另一个作为有限拓展；只有前一项产生稳定证据后才叠加下一项。尚未决定最终路线。

## 01 路线 A PINN 稀疏观测重构

### A1 推荐范围

第一阶段只做一个已验证工况下、明确子区域中的温度重构或少量有效热输运参数辨识；避免直接从有限顶棚温度推断完整三维燃烧、速度、压力、辐射和 CO 场。

可选起点：远离火焰反应核心的顶棚烟气区域。物理约束可考虑适用的热输运/能量平衡，但必须说明速度、有效扩散、壁面热损失等量是已知、由 CFD 提供还是待辨识。若输入了 CFD 的完整速度场，结论应写“在已知速度条件下重构温度”，不能写“仅凭几个温度传感器恢复全部流场”。

若只依据 Peng 的稳态天花曲线建立经验方程约束，应称为物理引导/经验约束回归，不能冒充完整 Navier–Stokes PINN。Peng 的二维/三维不均匀性和近源强羽流，决定了简单纯导热方程一般不足以代表整个火灾舱。

### A2 能复用什么

- [DeepXDE](https://github.com/lululxvi/deepxde)：复用自动微分、PDE/ODE 残差、观测损失、边界条件、训练器和逆问题接口。
- 官方 [Navier–Stokes inverse example](https://github.com/lululxvi/deepxde/blob/master/examples/pinn_inverse/Navier_Stokes_inverse.py) 可参考程序结构；它是二维不可压圆柱绕流，不能直接替换坐标就用作火灾模型。
- 若未来需要更大的 Physics-ML 工作流，可评估 [NVIDIA PhysicsNeMo](https://github.com/NVIDIA/physicsnemo)，但不是本项目起步的必要依赖。
- 火灾相关方法依据：[Velocity Reconstruction in Puffing Pool Fires with PINNs, arXiv:2208.03542](https://arxiv.org/abs/2208.03542)。论文用数值数据和密度/压力/温度观测推断速度；这支持研究方向，不证明只有少量顶棚温度就足够。本轮核对摘要和书目信息，未复现该论文代码。

### A3 怎样证明是有价值的创新

| 对照实验 | 要回答的问题 |
| --- | --- |
| 简单插值/回归 vs 普通 NN vs PINN | 物理约束是否提供真实增益，而非只有网络容量差异 |
| 不同测点数和布置 | 减少观测后误差如何变化；靠近火源和开口的点是否更重要 |
| 去掉物理残差的消融 | 改进是否真的来自物理先验 |
| 噪声或测点失效 | 传感器偏差/丢失时是否仍可信 |
| 空间区域、时间段及整工况的分离测试 | 是插值、跨时间预测还是跨工况泛化，分别成立到什么程度 |

建议报告：未观测点温度/温升的 MAE 或 RMSE、峰值误差、关键位置低估、残差、训练成本和推断时间。稀疏度可作为实验变量，但本轮不预设任何成功率或速度提升。

把连续 CFD 数据随机拆成相邻训练/测试点容易高估效果。训练、调参和测试应隔离；如声称跨 OP 或 HRR 泛化，就必须留出整个 OP/HRR 测试，且承认只有四个基本状态不足以证明广泛泛化。训练时间也属于成本，不能只报一次推断比一次 CFD 快。

仅在 CFD 生成的参考场上重构成功属于**合成观测上的方法验证**；不能写成真实传感器现场验证。原实验曲线可作为独立检查，但其稀疏性、测量物理与数字化误差需保留。

温度重构成功不等于 soot/CO/visibility 重构成功。即使生成了光滑温度层界面，也不能自动用于烟层安全判定。

## 02 路线 B MOOSAS 补风筛选与多方法比较

### B1 已有资源和真实边界

[KLEGB/MOOSAS](https://github.com/KLEGB/MOOSAS) 的 MoosasPy 提供几何转换、模型交换、能耗、辐射/采光、气流和耦合工作流。它是建筑性能分析工具包，不是本项目已验证的火灾反应流求解器。

本机 `C:\Users\lyuml-win\Desktop\building-services-agent` 已保留 MOOSAS 复用记录和接口代码。`docs/MOOSAS_MODULE_MAP.md` 记录了几何/模型交换的有界测试，以及气流/原生引擎的历史运行限制；这些不是本作业火灾模拟通过的证据。本轮只读取资料和源码，未调用任何已有 probe、仿真或优化程序。

### B2 适合的附加任务

1. 复用空间/开口描述，将排烟量、补风路径、压力和开口阻力需求整理成一致的数据接口。
2. 在明确温度和压差边界、适用的开口流量系数下，评估准稳态气流网络作为**方案筛选器**是否合理。
3. 对比网络预测与 CFD 在开口质量流量、压差和流向上的差异；同时观察网络无法反映的温度分层、卷吸和烟气短路。
4. 如果筛选器确实有效，再用于排除明显不合理的方案，减少后续昂贵计算，而不直接宣称输出即最终消防设计。

单个热区的平均温度网络无法自动解析一个开口同时上部排烟、下部进气的双向分层流。若要分高度/分区，应有物理和接口依据；人为增加很多节点也不等于已恢复 CFD。示范网络中的普通建筑内热增益和温度默认值不能代替火源、热烟层和反应过程。

本作业几何很简单，如果为了画一个盒子而花大量时间接 IFC/几何识别，收益很小。更有意义的 MOOSAS 创新是**它的低成本气流筛选在什么范围有效、何时失效，以及能否帮助设计决策**。

### B3 多目标优化可以怎样接上

在已确认允许改动的前提下，可比较排烟口位置/面积、烟帘位置/垂深、补风面积和机械排烟量。安全条件先设为约束，再比较能耗、设备数量或面积/成本代理量，避免加权平均把不安全设计“平均成优”。

MOOSAS 的名称和论文涉及多目标设计，不代表当前安装已提供可直接调用的消防优化器。需要检查实际接口。可复用 [pymoo](https://github.com/the-dual-space/pymoo) 的多目标算法或 [Optuna](https://github.com/optuna/optuna) 的试验管理/优化；选择一个即可，不必重写优化器或同时堆叠多个框架。

优化前沿上的候选应由独立 CFD 情景复核，尤其是高烟产率、补风受限和选定故障情景。仅在训练样本或粗筛网络上最优，不等于高保真验证通过。固定几何下的不同烟产率属于不确定/加严工况，不应偷偷成为优化器可自由选择的“降烟”变量。

## 03 其他方法可作为哪里的一块

| 方法 | 合适用途 | 不适合声称什么 |
| --- | --- | --- |
| Peng 经验关联式和手算质量/能量平衡 | 物理量级检查和简单基线 | 不能替代新排烟口/烟帘情况下的三维验证 |
| [CFAST](https://github.com/firemodels/cfast) 等分区模型 | 经适用性检查后的快速对照 | 长细、强空间非均匀舱体不一定满足均匀分区假设；不是天然正确的替代场模型 |
| [SALib](https://github.com/SALib/SALib) | 识别哪些设计/物理参数最影响结果 | Sobol/Morris 需要相应采样及计算预算，不能只有四个基本案例就声称全局敏感性充分 |
| [scikit-learn](https://github.com/scikit-learn/scikit-learn) 的简洁代理模型 | 数据量适合时建立便宜的响应面，作为 PINN/优化的对照 | 很小数据集上高训练拟合度不表示预测可靠，更不能因此堆大网络 |
| 简单传感器/延迟控制逻辑 | 可选的排烟启停、测点失效研究 | 必须计入启动延迟、失效方式和控制误报，不是动画中手动调风机就叫智能控制 |

下载快照、导入库或安装 MCP 本身都不是论文/报告的创新贡献。贡献应能回答“采用这一方法后，少了多少观测/筛掉多少无效方案/改善什么决策，在什么条件下有效”。保留第三方作者、许可、commit 和修改记录；不把他人算法归为原创。

本轮新增调研的 DeepXDE/MOOSAS/SALib/pymoo 等均未在本工作区安装、连接或测试。

## 05 推荐的创新验收与止损条件

**主创新候选：PINN 稀疏温度重构 + 测点布置比较。** 它利用已经为作业产生的数据，能明确设置对照，较容易区分“做了一个网络”和“解决了少测点问题”。

**第二候选：MOOSAS 气流网络筛选 + 安全约束下的排烟设计优化。** 它更偏工程决策与方法比较，接口与分层适用性风险较高。若现有气流接口无法表示所需边界，应缩小研究问题或停止，不为使用某软件而编造物理适用性。

两个候选尚无性能结论。若 PINN 不优于插值/普通 NN，就保留失败分析，不能只换测试集；若低保真网络不能可靠排序，就报告适用边界，不能用其替代最终验证。全球原创性尚未做系统文献查新，只可称本课程项目中的方法拓展和创新尝试。

完整的“CFD → 稀疏观测 → PINN → 网络筛选/优化 → CFD 复核”是可选扩展框架，不是本轮批准开始实现的工作清单，也不要求一次全做。

# Group 18 丙烯排烟代理模型试验

目标是估计一个完整 FDS 工况在 0–120 s、八个测站所有输出时刻中的最低烟层高度。门槛为 0.38 m。这是对已采样的 FDS 设备输出建模，时间步之间和测站之间的极值仍未知。丙烷验证数据未参与训练。

## 检索与实现选择

- 工程小样本代理建模已有 Kriging、线性响应面等路线。选取常数基线、双输入线性回归与平方指数核高斯过程（GP）比较。直接调用本项目已有的 replay_search.read_fds 和 predict，线性回归使用 NumPy 的最小二乘。未安装新工具箱。[SMT 源码](https://github.com/SMTorg/smt) · [SMT 2.0 论文](https://arxiv.org/abs/2305.13998)
- DeepXDE 提供 PDE 残差与边界条件训练接口。当前标签是时空极小值，对它关于垂壁深度或风量求导不能得到烟气质量守恒方程。要走 PINN 路线，需要另选有时间或空间坐标的状态量并定义源项、补风和排烟边界。对流问题的 PINN 还需检验优化收敛。本试验选择可直接验证的标量代理。[DeepXDE 源码](https://github.com/lululxvi/deepxde) · [PINN 失效模式研究](https://arxiv.org/abs/2109.01050)

## 数据与检验

两套布局独立拟合，均为 OP-6。原布局使用垂壁深度 0、0.08、0.16、0.24 m 与总风量 0.08、0.16、0.24、0.32 m³/s 的组合，烟炱产率固定为 0.02。高位补风布局固定总风量 1.28 m³/s，改变深度（0.16、0.24 m）与烟炱产率（0.02、0.05、0.10）。FDS 输入、网格、边界与运行元数据沿用各 case 的原始记录。原布局由既有汇总器读取，六组高位补风标签也已逐一与本地原始设备输出核对。

每轮留出一整组，其余同布局工况用于拟合。基线取训练集均值。GP 的固定特征尺度为深度 0.08 m，第二维取风量 0.08 m³/s 或烟炱产率 0.04。尺度是建模假设，未按测试误差调参。留出边缘点时会考验模型的外推能力。

|布局|模型|平均绝对误差 mm|最大绝对误差 mm|误报通过数|
|---|---|---:|---:|---:|
|原布局|均值|21.9|30.4|0/16|
|原布局|线性|9.6|17.7|0/16|
|原布局|GP|14.2|26.4|0/16|
|高位补风|均值|59.1|99.6|0/6|
|高位补风|线性|61.3|116.8|0/6|
|高位补风|GP|129.1|178.5|3/6|

22 个 FDS 标签均低于门槛，因此无法估计对真正达标工况的识别率。原布局最好的实测算例仍比门槛低约 285 mm。高位补风更接近门槛，但改变深度的影响随烟炱产率而变，有时还会改变最差测站。六组数据支持这种现象的描述，尚不足以可靠预测新设计的最差站或达标边界。0.32 m 深垂壁在高位补风训练范围外。

## 复现

在仓库根目录运行（Python、NumPy 和 Node.js）：

```sh
python 06_Tools/check_layer_surrogate.py
python 06_Tools/check_layer_surrogate.py --original 0.12 0.20
python 06_Tools/check_layer_surrogate.py --tall 0.20 0.05
```

第一条输出逐工况留出的 CSV。后两条使用对应布局全部已知样本，输出三种估计的最低高度（m）。输入顺序为垂壁深度与总风量，或垂壁深度与烟炱产率。查询限定在各自采样矩形内。可核对[逐工况预测](../05_Calculations/layer_surrogate_holdouts.csv)和[高位补风 FDS 最差站位与时刻](../05_Calculations/tall_makeup_op6_completed_scenarios.csv)。
